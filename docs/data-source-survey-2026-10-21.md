# 数据源调研与采集计划

> 日期：2026-10-21。范围：全水产养殖领域（不限品种），来源不限于农业农村部门。
> 方法：**先发现 → 再评估 → 后导入**。本文所有"可达性"均为当日实测（`curl` + 真实响应），
> 不是文献转述；无法访问的来源如实标注，不臆测内容。

## 一、判定标准

每个来源记录 9 个维度：

| 维度 | 说明 |
|---|---|
| 资料类型 | 标准 / 技术指南 / 科研论文 / 一般知识 / 公开 QA / 术语 |
| 主题覆盖 | 物种、水质、苗种、饲料、疾病、用药、设备、环境 |
| 语言 | 中文 / 英文 |
| 发布日期 | 是否可追溯到具体日期 |
| 权威性 | 对应 `authority_level` 受控词表 |
| 全文可访问性 | 实测：可直接下载 / 需登录 / 仅元数据 / 网络不可达 |
| 许可 | 明确许可协议或"未声明" |
| 解析难度 | 文本 PDF 易 / 扫描件难 / HTML 中 / JS 渲染难 |
| 预期用途 | 知识库语料 / FAQ 问题源 / 术语归一化 / 评测参考 |

**红线**：`robots.txt` 为 `Disallow: /` 的站点不做自动抓取；未声明许可的资料不进入对外发布物。

### 2.4 术语资源评估（专项）

| 资源 | 能否用于归一化 | 结论 |
|---|---|---|
| **AGROVOC** | ✅ 多语 SKOS，含 `zh` 标签与 `altLabel`，REST 可取 | **首选**。可构建"中文名 ↔ 拉丁学名 ↔ 英文名 ↔ 同义词"表，直接喂 `species.py` 的别名表与 BM25 `CUSTOM_TERMS` |
| **GB/T 22213—2026 水产养殖术语** | ⚠️ 标准全文非公开（仅元数据/预览） | 作为**术语口径校准依据**引用；不复制全文。若通过图书馆获得，可抽取术语条目（属合理使用范围，标注出处） |
| **FishBase** | ✅ 物种名与异名 | 补充拉丁学名与俗称映射，注意克制抓取 |
| 现有 `species.py` | 已有 4 组别名 | 需扩展到草鱼、罗非鱼、鲤、鲫、鲈、石斑鱼、大黄鱼、紫菜、海带、牡蛎、扇贝等 |

术语归一化的产出不是"词表文件"，而是：
1. `species.py` 别名扩充（可测试）；
2. `CUSTOM_TERMS` 扩充（改善 BM25 切分）；
3. 图关系种子（`graph_entities`/`graph_aliases`）：物种—疾病—病原—水质指标。

## 四、分批采集计划

### 第一批（试点，20–30 份）
目标：验证解析、引用定位、元数据完整性，而非追求数量。

| # | 来源 | 数量 | 选取策略 |
|---|---|---|---|
| 1 | WorldFish | 12–15 | 按物种分层：tilapia / carp / shrimp / crab / catfish 各 2–3；优先 CC BY、2015 年后、PDF < 15MB |
| 2 | 全国水产技术推广总站 | 3–4 | 五大行动通知、用药明白纸、病情月报 |
| 3 | agri.cn | 2–3 | 病害预测预报（当月 + 历史一期，用于时效对比） |
| 4 | WOAH | 2–3 | 水生动物法典相关章节（疾病列表、水生动物卫生监测） |
| 5 | 现有标准 | 3 | DB36 / DB46 / DB32（已在库，补齐元数据） |

### 第二批（扩面）
- WorldFish 追加 30–50 份，补鲤科、海水鱼、贝藻；
- 省级推广站（浙江、江苏、广东、湖北、海南）技术规程；
- FAO 全文（网络放开后或人工下载）；
- 标准：GB 11607、GB/T 22213、SC/T 2068、GB 31650（人工/图书馆）。

### 第三批（按实验结果决定）
只有当第二批的主题覆盖与检索指标仍不足时才扩充；**不以文档数作为完成标准**。

## 五、每批必须统计的指标

不以"导入了多少文档"衡量成果。每批产出：

| 指标 | 计算方式 |
|---|---|
| 新增物种数 | 去重后的 `species` 取值数 |
| 新增知识主题 | `category` × `growth_stages` 组合数 |
| 文档数 / 版本数 | 入库成功计数 |
| 有效 Chunk 数 | 通过长度/去噪阈值的 child chunk 数 |
| 解析失败率 | 失败版本 / 提交版本 |
| 来源完整性 | 有 `source_url` + `source_org` + `publish_year` 的比例 |
| 问答覆盖 | 用固定探针问题集测各主题是否"有证据可答" |
| 许可标注率 | 有明确 license 的比例 |

## 六、风险与对策

| 风险 | 对策 |
|---|---|
| 政府网站禁止抓取 | robots 强制校验；moa 走人工投放 |
| 网页内容变动 | 记录 `fetched_at` + `content_hash`；内容变化即新版本 |
| 英文资料与中国养殖条件不符 | `authority_level=international` + 元数据 `region`；回答时提示适用条件，**不得当作中国现行规范** |
| 未声明许可 | 只做内部检索与论文引用，不对外发布原文；对外只发布题目与证据引用 |
| 扫描件解析质量差 | 首批抽查表格/页码；必要时引入 MinerU |
| 品类扩张导致语料稀释 | 按主题覆盖与实测指标扩容，不按数量 |
