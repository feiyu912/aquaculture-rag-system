# 待定项

> 技术方案已定稿；以下事项不阻塞架构，但会影响数据准备、实验规模和部署方式。每项明确“谁来定、何时定、默认方案”。

## 1. 数据来源与授权（当前最关键）

| 问题 | 需要确认 | 默认方案 |
|---|---|---|
| 陶江老师是否有现成水产资料 | 资料清单、格式、是否允许用于毕设 | 若有，优先使用并请老师推荐权威来源 |
| 权威来源范围 | 教材、推广站手册、期刊、行业标准 | 以公开教材/推广站/标准为主，期刊论文为辅 |
| 授权与引用 | 是否可复制 PDF、是否可入库 | 仅本地演示，不公开分发；论文标注来源 |
| 品种范围 | 中华绒螯蟹、凡纳滨对虾是否足够 | 先做这两个品种，资料不足再调整 |
| 数据质量 | 是否含表格、扫描件、旧版资料 | 优先可复制文本 PDF；扫描件走 OCR |

**给陶老师的问题清单：**

1. 您手上是否有可用于毕设的水产养殖教材、培训手册或推广资料？是否方便提供电子版？
2. 您建议优先覆盖哪些品种和主题（水质、病害、饲料、养殖管理）？
3. 是否有推荐的权威来源或需要避免的非权威资料？
4. 资料是否涉及未公开内容或版权限制？
5. 能否帮忙审核 20–30 条核心评测问题与答案要点？

**启动门槛**：至少 20 份可解析 PDF，覆盖 2 个品种、4 类主题，才进入阶段 2。不足时先用公开资料搭底座，不等待。

## 2. 硬件与模型部署

| 项 | 待定 | 影响 | 默认 |
|---|---|---|---|
| 是否有 GPU | 型号、显存、可否长期使用 | Reranker/MinerU 速度 | 无 GPU 则限制重排候选数，测延迟后定 Top-K |
| 部署机器 | 本地 / 实验室服务器 | Docker Compose 资源 | 本地 8C16G 起步，MinerU 单独 profile |
| DeepSeek 模型 | 具体模型名与快照 | 实验可复现 | 开发期用当前可用版本，实验期固定并记录 |
| API 预算 | 评测与开发调用量 | 实验规模 | 先小规模回归，正式实验集中跑 |
